# YourAnimes 開發工作狀況
## 2026 更新

### 08.28
* 作品頁改版：延續 08.16 新番表改版的視覺風格，作品頁的七個分頁（概覽／播出狀況／影像資料／數據統計／網友感想／週邊商品／書籍資料）與共用的抬頭、分頁列一併換成同一套版面與配色，本次更新內容如下
  * 抬頭重新排版：左封面（可點開放大、多張可切換）、中間作品資訊、右側數值盤（喜愛程度、追番人數、期待分數等）；新增「在哪看」一列，直接列出目前有上架的串流平台
  * 頁面頂端加上「動畫資料 › 季度 › 作品名 › 分頁」路徑，可直接回到該季新番表
  * 分頁列往下捲時固定在頂端、可左右滑動，固定時左側會縮出作品名
  * 播出狀況：免費觀看／月租觀看／單次租看／購買收藏改為一列一層級，平台改為「圖示＋名稱」（原本只有圖示）；Crunchyroll 標示字幕語言
  * 週邊商品改為商品卡片（有商品圖）
* 訂閱頁改版並新增年繳方案：版面與配色同樣換成新番表、作品頁那一套；年繳 NT$300 / 365 天（僅支援信用卡），月繳 NT$30 / 30 天維持不變
  * 按下訂閱後先顯示「前往付款」確認視窗，說明將前往綠界頁面與可用的付款方式，再離站付款
  * 訂閱成功頁改版：顯示已生效的權益、到期日與接下來可以去的地方；ATM／超商繳費入帳後下次進入訂閱頁也會看到一次
  * 付款確認中、付款未完成、待繳費（ATM 虛擬帳號／超商代碼）各狀態的說明更清楚，待繳費資訊附複製鈕
  * 訂單紀錄新增「方案」欄與訂單編號；訂閱須知更新（年繳僅支援信用卡；本站終止服務時，年繳依剩餘天數比例退款至原信用卡）

### 08.25
* 新番表完整卡點開圖片放大時，標題改為顯示每張圖各自的內容（「主視覺圖」「第二話預告」「製作決定宣傳影片封面」等）：過往左右切換圖片時標題只有作品名稱，看不出正在看的是哪一種圖。圖說由站方逐張標註，有機會時會補上

### 08.24
* 新番表支援「網路先行配信」：
  * 有網路先行的作品（ABEMA、dアニメストア、Prime Video 等），首播日排序與星期分組改以最快能看到的先行時間為準，時刻旁標示「先行」
  * 完整卡片新增「網路先行」資訊行：先行的星期、時刻（JST）、開始日與平台，與電視播出時段並列；同日開始但串流進度較快的作品標示「比電視提前 N 話」
  * 先行作品的「已播 N 話」改以串流實際更新進度計算（清單模式標示「（串流）」），不再是電視放送進度
* 「星期」排序的速覽格新增播出提示：播出時段內亮燈顯示「第 N 話」，播出當天顯示「今晚／今天第 N 話」，尚未開播但一週內首播的作品顯示「本週首播」

### 08.16
* 新番表改版
  * 頁面重整為「01 本季速覽／02 完整作品列表／03 跨季續播／04 累積觀看走勢」四個區塊；右側季度連結側欄移除，改為頁面頂端的季表導航（原側欄的其他連結在主選單的「今年動畫電影」「熱播動畫排行」「動畫喜愛排行」）
  * 「本季速覽」封面格陣改版：每格加上名次與放送狀態（倒數 N 天／未開播／放送中／第 N 話／完播），格上數值跟著目前排序改變（期待分數、累積觀看、集均觀看、喜愛程度、追番人數、首播日、播出時刻等）；依「觀看」「集均」排序時會按本季實際的數字分佈分級陳列、每級標出範圍與部數，依「星期」「版權」排序則分別按播出星期與版權商分段
  * 列表檢視改為「完整／清單」兩種（原本三種，移除「縮圖」）；清單模式一行一部，點該行就地展開完整卡片。作品卡片上的最愛愛心移至追番記錄視窗內
  * 篩選新增「類型」（全部／新作／續作／重製）與可複選的「元素」標籤（每項顯示本季部數）；「顯示」改為單選三項（全部／僅上架／含成人向），選「僅上架」後可再複選串流平台
  * 期待度改為 0～100 的「期待分數」：原本是「季前期待度：13.76」這類沒有上限的加權值，分數會被投票人數放大——票多但評價普通的作品會排在票少但大家很期待的作品前面；新分數只看期待程度本身（票數少的會往中間收斂，避免幾票就衝到極端值）。作品卡片上直接列出「必追／先看幾集／有空再看／不感興趣」四項的票數與百分比，投票改為點一下即送出、可隨時改投（原本要另開對話框選完再按確定）
  * 作品卡片：封面與劇照可點開放大（多張可左右切換）、串流資訊整合為「在哪裡看」區塊（台灣版權、台灣更新時段、各平台連結）、元素標籤點下去直接篩選本季（原本會跳到搜尋頁）；喜愛程度未滿 30 人評分時顯示「—」
  * 新增作品索引，可直接跳到列表中的任一部作品（視窗較寬時顯示在右側，較窄時為右下角「目次」鈕）
* 修正搜尋欄使用中文輸入法時，組字過程會被即時搜尋打斷、卡住無法繼續輸入的問題（筆畫等組字時間較長的輸入法較容易遇到）；組字中按 Enter 為選字確認，不會提前送出搜尋
* 修正部分作品加入最愛後，個人頁最愛區顯示灰色空框、沒有封面圖的問題（從追番視窗內按愛心較容易遇到，例如該作品還沒加入追番、或剛投完期待度時）；既有受影響的紀錄已一併補上封面
